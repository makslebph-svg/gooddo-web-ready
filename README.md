# GoodDo v24

Сайт: https://makslebph-svg.github.io/gooddo-web-ready/

Статическая музейная галерея со скроллом: студия, шоурил, пять залов кейсов, клиенты и отзывы, команда, контакты

Клиенты и отзывы представлены отдельными стеклянными карточками в двух колонках. Прокрутка над колонками остаётся внутри них, на фоне — продолжает маршрут. Меню имеет прозрачный тёмный градиент с затуханием

Формы подключены к существующей системе Tilda gooddo.ru. Политика конфиденциальности доступна по privacy.html

Новый кадр Рамиля временно соединяется с Максимом плавным растворением до подготовки соответствующего видео. Вход и выход команды также временные

Публикация через GitHub Pages из ветки main
