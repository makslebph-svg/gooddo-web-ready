# GoodDo v27

Сайт: https://makslebph-svg.github.io/gooddo-web-ready/

Обновлены все 12 роликов музейного маршрута, включая вход в команду и возвращение в атриум. Команда: Рамиль → Сергей → Валерия → Максим. Стеклянные плашки размещены по последней разметке пользователя, мобильное кадрирование следует за персонажем

Пролёт после экрана «О студии» продлён до середины галереи перед шоурилом, время перехода колесом — около 2,6 секунды. Карточки студии расположены сеткой 2×2. В разделе клиентов — карусель отзывов с портретами и полоса логотипов

Маршрут: H.264, 24 fps, 1404 кадра, 58,5 секунды. Компьютер — 1920×1080, телефон — 960×540. Форма использует существующую систему приёма заявок, политика доступна по privacy.html

Локально проверены остановки и переходы маршрута, прокрутка, четыре плашки команды на компьютере и телефоне. Публикация через GitHub Pages из ветки main
