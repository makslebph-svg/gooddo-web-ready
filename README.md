Первые два перехода обновлены утверждёнными роликами Kling: атриум → бассейн → бетонное дно → галерея, затем пролёт по галерее → картина справа → зал ИИ

Финальный проход: зал шоу и трансляций → потолочные светильники → бетонное перекрытие → вода бассейна → атриум. Один 6-секундный ролик Kling заменяет прежние переходы 8-9 и 9-10

Изображения WebP, маршрутное видео WebM с резервным MP4

Скролл по этапам: один жест автоматически доводит маршрут до следующей остановки. Обратный скролл возвращает к предыдущей. Остановки: главный экран, четыре титра, шоурил, пять залов, контакты и возвращение на главный экран. Карточки кейсов сохраняют прокрутку колесом и перетаскивание
