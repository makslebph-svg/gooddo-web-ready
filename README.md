# GoodDo v25

Сайт: https://makslebph-svg.github.io/gooddo-web-ready/

Один жест запускает спуск в галерею и непрерывный медленный пролёт через студию до шоурила. Четыре титра сменяются по времени видео, без промежуточных остановок. Медленный участок занимает около 14 секунд с мягкими разгоном и торможением

Использован отрезок существующего видео с локальным замедлением и интерполяцией, новая AI-генерация не запускалась. Для телефонов подключена облегчённая копия

После шоурила сохранён общий маршрут v24: пять залов кейсов, клиенты и отзывы, команда, контакты. Формы используют существующую систему Tilda gooddo.ru, политика доступна по privacy.html

Публикация через GitHub Pages из ветки main
