# GoodDo Gallery
     
Обновление v29 от 20 ноября 2026 года на основе полной сборки из брифа «Сайт.docx»

Для просмотра запустите `START.cmd` и откройте http://127.0.0.1:3063/

Главная и раздел «О нас» обновлены по документу. 20 работ распределены по четырём залам:

- Контент для ивентов — 4
- Графика и ИИ-видео — 6
- Постановочная съёмка — 5
- Репортажная съёмка ивентов — 5

В каждом зале доступны ссылки на остальные категории. Между постановочным и репортажным залами используется пролёт Kling. Обе версии маршрута имеют 1283 кадра при 24 кадрах/с, длительность 53,46 секунды. Сайт выбирает видео 1920 × 1080 для компьютера и 960 × 540 для телефона.

Главная, навигация, окно кейса, отзывы и форма обновлены. Стили обеих точек входа (`index.html` и `review.html`) собраны в `site.css`. Шоурил использует `assets/case-media/showreel-2025.mp4`. Форма использует существующее подключение Tilda.

Видео и постеры хранятся локально в `assets/case-library`. Описания и ссылки на источники можно обновлять в `case-data-full.js`, категории — в `hall-data-full.js`, привязку видео и постеров — в `case-media-update.js`.

Раздел «Наша команда» использует пять новых пролётов. Камера подлетает к Рамилю, затем открывает Сергея, Валерию и Максима, поднимается через бассейн и возвращается к атриуму. Имена участников привязаны к финальным кадрам соответствующих пролётов.

При подлёте к шоурилу плавно размывается фон за плеером. В финальном блоке сохранена одна ссылка на политику конфиденциальности в строке согласия.

«ЛужникиЛужники» исправлено на «Лужники». Для «Зелёного марафона» убрана длительность «двухминутный» из описания, поскольку приложенный ролик длится около 78 секунд.

Версия для просмотра на [GitHub Pages](https://makslebph-svg.github.io/gooddo-web-ready/?v=29).
