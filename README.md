# GoodDo v23

Сайт: https://makslebph-svg.github.io/gooddo-web-ready/

Статический сайт с видеомаршрутом, управляемым прокруткой

«Наша команда» встроена в общий маршрут после залов портфолио: Рамиль → Максим → Сергей → Валерия

Имена и должности размещены на прозрачном матовом стекле, без стрелок и дополнительных кнопок перехода

Три пролёта команды собраны в оптимизированные видео MP4 и WebM для компьютеров и мобильных устройств. До подготовки входного и выходного роликов используются временные плавные переходы

Публикация выполняется через GitHub Pages из ветки main
