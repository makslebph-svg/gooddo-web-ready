# GoodDo — веб-сборка

Для публикации загрузите содержимое этой папки целиком в GitHub Pages или на статический хостинг

Изображения WebP, видео MP4 H.264 с faststart. У видео маршрута короткий интервал ключевых кадров для прокрутки в обе стороны. Видео кейсов загружаются при открытии. Исходники и материалы для генерации в публикацию не включены

Локальный просмотр: START.cmd, http://127.0.0.1:3021

Видео WebM/VP9 подключены как основной формат. MP4 оставлены для браузеров без VP9. Изображения WebP
